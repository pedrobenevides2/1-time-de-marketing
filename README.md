## Painel Visual (`painel.html`)

Interface web completa acessível em [GitHub Pages](https://pedrobenevides2.github.io/1-time-de-marketing/painel.html).

### Funcionalidades

- **Escritório em organograma** — 4 andares hierárquicos (CEO → Diretoria → Coordenação → Especialistas)
- **Personagens fictícios** nas cadeiras vazias: Bete das Planilhas 🧮, Seu Geraldo da TI 🔧, Fernandinho do Café ☕
- **Estagiário event-driven** — se move entre mesas somente ao transferir dados entre agentes
- **Speech bubbles de status** em cada mesa: 💤 idle · ⚙️ processando · 💬 ativo · ✅ entregue
- **27 esteiras de processo** com fluxogramas navegáveis e zoom (+/−/scroll)
- **Chat integrado** com qualquer agente via Anthropic API
- **Entregáveis** detectados automaticamente e disponibilizados para download
- **Google Drive** — entregáveis sobem automaticamente para pasta configurada com link compartilhável
- **Google Sheets** — cada conversa salva em 8 colunas: Horário · Agente · Nickname · Atividade · Esteira · Input · Resposta · Link Drive
- **Filtros por categoria** (G/A/B/C/D/E/F) e gerenciamento individual de esteiras
- **Modo compacto** e **prompt caching** configuráveis

### Configuração inicial

1. Abra `painel.html` no navegador (ou acesse o link do GitHub Pages)
2. Clique em **⚙ Config** e preencha:
   - **Anthropic API Key** — obtenha em [console.anthropic.com](https://console.anthropic.com)
   - **Client ID OAuth 2.0** — Google Cloud Console → Credenciais → OAuth
   - **ID da Planilha** — URL do Google Sheets: `spreadsheets/d/`**ID**`/edit`
   - **ID da Pasta no Drive** — URL da pasta: `drive/folders/`**ID**
   - **Produto/Empresa** e **ICP** — contexto para os agentes
3. Clique **🔗 Conectar Google** (autoriza Sheets + Drive de uma vez)
4. Clique **📋 Init** para criar os cabeçalhos na aba "Conversas" (apenas na primeira vez)

### Integrações do stack gratuito (opcionais)

Configure em ⚙ Config → Integrações:

| Campo | Onde encontrar |
|-------|---------------|
| GA4 Property ID | Painel GA4 → Admin → Property Settings |
| GA4 Measurement ID | GA4 → Admin → Data Streams → ID (G-XXXXX) |
| Search Console Domínio | `sc-domain:seusite.com.br` |
| Service Account E-mail | Google Cloud → IAM → Service Accounts |
