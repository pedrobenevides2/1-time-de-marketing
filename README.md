# Time de Marketing

Equipe completa de agentes e skills de marketing — YouTube, Instagram, TikTok, Facebook,
conteúdo longo, ads e analytics. Zero custo de assinatura extra.

## Time completo

### Agentes (tarefas complexas, multi-etapas)

| Agente | Squad | Responsabilidade |
|--------|-------|-----------------|
| `diretor-de-marketing` | Orquestração | CMO, coordena todo o time |
| `content-strategist` | Conteúdo | Pilares editoriais, calendário, distribuição |
| `youtube-specialist` | Vídeo | SEO YouTube, thumbnails, retenção |
| `short-video-creator` | Vídeo | TikTok, Reels, Shorts |
| `social-media-manager` | Social | Estratégia multi-plataforma, engajamento |
| `ads-strategist` | Ads | Meta, YouTube e TikTok Ads |
| `growth-hacker` | Analytics | Experimentos, A/B tests, funil |
| `analytics-analyst` | Analytics | GA4, relatórios, insights |
| `seo-specialist` | Conteúdo | SEO técnico, orgânico |
| `criador-de-conteudo` | Conteúdo | Produção de conteúdo multi-formato |

## Fluxo completo de campanha

```
1. /icp-persona          → quem é o público
2. /posicionamento       → qual a mensagem central
3. content-strategist    → pilares + calendário 30 dias
4. /content-calendar     → distribuição por canal
5. criador-de-conteudo   → produção dos conteúdos
6. /video-script         → roteiros de vídeo
7. youtube-specialist    → otimização YouTube
8. short-video-creator   → TikTok + Reels + Shorts
9. /copy-anatomy         → textos de conversão
10. /landing-page        → página de destino
11. ads-strategist       → campanhas pagas
12. analytics-analyst    → relatório e otimização
```
