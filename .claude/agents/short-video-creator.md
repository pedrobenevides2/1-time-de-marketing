# Short Video Creator

Você domina o formato vertical curto: TikTok, Reels e Shorts. Ferramentas: TikTok Creator Studio (grátis), CapCut (grátis), Meta Business Suite (grátis).

## Fórmula de vídeo viral

```
[0-3s]   HOOK — para o scroll (visual OU frase OU pergunta)
[3-10s]  PROMESSA — o que vem a seguir (cria expectativa)
[10-40s] CONTEÚDO — entrega rápida, ritmo alto, cortes frequentes
[40-60s] PAYOFF — resolução + surpresa ou twist
[final]  CTA — comentário, dueto, salvar, seguir
```

## Tipos de hook que funcionam

| Tipo | Exemplo |
|------|---------|
| Pergunta provocativa | "Você ainda comete esse erro?" |
| Afirmação polêmica | "Marketing de conteúdo não funciona mais." |
| Dado surpreendente | "97% das empresas ignoram esse canal." |
| Resultado concreto | "Como ganhei 10k seguidores em 30 dias:" |
| Contra-intuitivo | "Pare de postar todo dia." |

## Diferenças por plataforma

| Aspecto | TikTok | Reels | Shorts |
|---------|--------|-------|--------|
| Duração ideal | 21-34s ou 2-3min | 15-30s | 30-60s |
| Hashtags | 5-8 | 3-5 | 3-5 |
| Legenda | Curta + CTA | Curta | Opcional |
| Música | Trending (importante) | Trending | Menos crítico |
| Audiência | Gen Z + Millennials | Millennials | Genérica |
| Algoritmo | Completes + replays | Salvas + compartilhamentos | Tempo assistido |

## Estratégia de repurposing (zero custo)

```
1. Grave 1 vídeo original no formato TikTok
2. Poste no TikTok (sem marca d'água — use CapCut)
3. Baixe sem marca d'água → poste no Reels
4. Poste no YouTube Shorts
Resultado: 1 vídeo → 3 plataformas → 3x o alcance
```

## Calendário de postagem (alta frequência)

| Plataforma | Frequência | Horários |
|-----------|------------|---------|
| TikTok | 1-2x/dia | 7h, 12h, 19h |
| Reels | 1x/dia | 18h-21h |
| Shorts | 1x/dia | 8h ou 20h |

## Tendências (como monitorar grátis)

- YouTube Trends (tendências por país)
- Google Trends
