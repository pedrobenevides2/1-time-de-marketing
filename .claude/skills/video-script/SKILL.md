# Video Script

## Defina antes de escrever
1. Plataforma: YouTube / TikTok / Reels / Shorts / VSL
2. Duração: ___ minutos/segundos
3. Objetivo: educar / entreter / vender / awareness
4. CTA final: inscrição / compra / link / comentário

## Formato do roteiro

```
[TÍTULO DO VÍDEO]
[DURAÇÃO ESTIMADA]
[PLATAFORMA]

---

[0:00-0:05] HOOK
CÂMERA: close no rosto / texto na tela / B-roll impactante
FALA: "[primeira frase que para o scroll]"
NOTA DE EDIÇÃO: corte rápido, música de fundo

[0:05-0:30] CONTEXTO / PROBLEMA
CÂMERA: médio, expressivo
FALA: "[contexto que cria identificação]"
TEXTO NA TELA: [destaque a palavra-chave principal]

[0:30-X:XX] DESENVOLVIMENTO
CÂMERA: alterna entre rosto e B-roll / tela gravada
FALA: "[conteúdo principal dividido em blocos]"
NOTA DE EDIÇÃO: corte a cada 3-5s, sem silêncios mortos

[X:XX-final] CTA
CÂMERA: close, olhando para câmera
FALA: "[ação específica que quero que façam]"
TEXTO NA TELA: [botão / seta / highlight do CTA]
```

## Regras por formato

| Formato | Duração | Hook | Ritmo |
|---------|---------|------|-------|
| YouTube | 8-15min | 30s | Médio, capítulos |
| Shorts/Reels | 30-60s | 2s | Rápido, sem pausa |
| TikTok | 21-34s | 3s | Muito rápido |
| VSL (vendas) | 15-30min | 60s | Narrativo |

## Marcações de edição
- `[CORTE]` — novo ângulo ou cena
- `[B-ROLL]` — imagem de cobertura
- `[TEXTO]` — legenda ou texto animado na tela
- `[MÚSICA ▲]` — aumentar volume da trilha
- `[MÚSICA ▼]` — diminuir volume da trilha
