# TikTok Strategy

## Pesquisa gratuita antes de começar
- **TikTok Creative Center** (ads.tiktok.com/creative-center): trending sounds, hashtags, vídeos virais por nicho
- **TikTok Search**: autocomplete revela o que o público busca
- **Aba "Explorar"**: tendências em tempo real

## Pilares de conteúdo TikTok (regra 40/30/20/10)
- **40% Educativo**: ensine algo útil do seu nicho
- **30% Entretenimento**: humor, bastidores, relatable
- **20% Inspiracional**: transformações, conquistas, motivação
- **10% Promocional**: produto/serviço (máximo isso)

## Tipos de vídeo por objetivo

| Objetivo | Formato | Duração |
|----------|---------|---------|
| Crescer seguidores | Tutorial ou lista | 30-60s |
| Viralizar | Trend com twist do nicho | 15-30s |
| Converter | Problema + solução | 45-90s |
| Engajar | Pergunta ou opinião | 15-30s |
| Autoridade | POV / "o que eu faria" | 60s |

## Estratégia de hashtags

```
5-8 hashtags por vídeo:
- 2x nicho específico (10k-100k posts)
- 2x nicho médio (100k-1M posts)
- 1x trending relevante (>1M)
- 1x marca própria
```

## Calendário semanal sugerido

| Dia | Tipo de conteúdo |
|-----|-----------------|
| Seg | Educativo (dica prática) |
| Ter | Trend do nicho |
| Qua | Bastidores / entretenimento |
| Qui | Educativo (lista ou tutorial) |
| Sex | Inspiracional |
| Sáb | UGC ou resposta de comentário |
| Dom | Recapitulação ou teaser da semana |

## Crescimento orgânico (sem anúncio)

1. Responda comentários nas primeiras 2h (aumenta o alcance)
2. Use Dueto e Stitch de vídeos virais do nicho
3. Trend + nicho = fórmula de viralização
4. Poste nos horários de pico: 7h, 12h, 19h (horário local)
5. Lives semanais aumentam o alcance dos vídeos do canal
