# Copy Anatomy

Escolha o framework adequado ao objetivo e escreva copy de alta conversão.

## Frameworks disponíveis

### AIDA (Anúncios, emails, posts)
- **A**tenção: headline que para o scroll
- **I**nteresse: problema ou dado relevante
- **D**esejo: benefício + prova social
- **A**ção: CTA claro e urgente

### PAS (Conteúdo educativo, emails de nurturing)
- **P**roblema: nomeie a dor com precisão
- **A**gitação: mostre o custo de não resolver
- **S**olução: posicione o produto como saída

### FAB (Descrições de produto, comparativos)
- **F**eature: o que é / o que tem
- **A**dvantage: por que isso importa
- **B**enefit: o que muda na vida do cliente

### Hook-Story-Offer (Social media, VSL)
- **Hook**: primeira linha que prende (pergunta, dado, provocação)
- **Story**: contexto que cria conexão e credibilidade
- **Offer**: o que você está pedindo ou oferecendo

## Regras de copy de alta conversão

- Headline = 80% do trabalho. Reescreva 5x antes de aceitar
- Fale para UMA pessoa, não para "vocês"
- Benefício > feature. Sempre pergunte "e daí?" após cada feature
- Objeção principal deve ser endereçada antes do CTA
- CTA específico ("Baixe o guia grátis") > genérico ("Saiba mais")
- Prova social próxima ao CTA dobra conversão

## Entregáveis

Para cada copy, entregue:
1. Versão principal (framework escolhido)
2. Headline alternativa (3 opções)
3. CTA alternativo (2 opções)
