# YouTube Ads

## Tipos de anúncio

| Tipo | Duração | Pulável? | Melhor para |
|------|---------|----------|------------|
| In-Stream pulável | 12s+ (cobra após 30s) | Sim, após 5s | Awareness + conversão |
| In-Stream não-pulável | 15-20s | Não | Mensagem curta e direta |
| Bumper | 6s | Não | Reforço de marca |
| Discovery | Qualquer | N/A | Capturar intenção de busca |
| Shorts Ad | <60s | Sim | Alcance em Shorts |

## Os primeiros 5 segundos (antes do "pular")

São os mais importantes — o usuário vai pular após isso se não for pego.

```
Segundos 1-2: Visual impactante OU frase que gera curiosidade
Segundos 3-5: Nome da marca OU promessa central

Evitar: logos lentos, animações, intros genéricas
```

**Fórmulas de hook em 5s:**
- "Você está perdendo [X] porque..."
- "Em [X dias], você pode..."
- "[Nome da marca] — [benefício único em 4 palavras]"

## Script de In-Stream (30-60s)

```
[0-5s]  Hook (antes do skip)
[5-15s] Problema ou contexto
[15-40s] Solução / produto
[40-55s] Prova social ou demonstração
[55-60s] CTA com URL ou card
```

## Segmentação (Google Ads — gratuito para configurar)

- **Palavras-chave**: exibe no vídeo antes/durante conteúdo relacionado
- **Tópicos**: categoria de conteúdo do vídeo exibido
- **Canais específicos**: anuncie nos vídeos de concorrentes ou parceiros
- **Público de intenção**: pessoas que pesquisaram termos relacionados
- **Remarketing**: visitantes do site, lista de clientes

## KPIs de YouTube Ads

| Métrica | Meta |
|---------|------|
| View Rate (In-Stream) | >30% |
| CTR (Discovery) | >1% |
| CPV (custo por visualização) | R$0,10-0,50 |
| CPL (se objetivo leads) | Depende do ticket |

## Orçamento mínimo

- Comece com R$20-30/dia para testar
- Use remarketing primeiro (menor CPV, maior conversão)
- Expanda para públicos frios após validar a mensagem
