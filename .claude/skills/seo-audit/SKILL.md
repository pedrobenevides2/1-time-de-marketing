# SEO Audit

Execute uma auditoria rápida de SEO e entregue problemas priorizados.

## Checklist de auditoria on-page

### Técnico (P0 — crítico)
- [ ] Title tag: 50-60 caracteres, palavra-chave principal no início
- [ ] Meta description: 150-160 caracteres, CTA implícito
- [ ] URL: curta, legível, palavra-chave inclusa, sem parâmetros desnecessários
- [ ] H1: único por página, inclui palavra-chave principal
- [ ] Canonical tag: configurada corretamente
- [ ] Status de indexação: página está sendo rastreada e indexada?

### Conteúdo (P1 — importante)
- [ ] H2/H3: estrutura hierárquica lógica com variações da palavra-chave
- [ ] Palavra-chave principal: presente no primeiro parágrafo
- [ ] Densidade de palavra-chave: natural, sem stuffing (1-2%)
- [ ] Conteúdo: responde completamente a intenção de busca?
- [ ] Tamanho: adequado para o tipo de query (informacional > transacional)
- [ ] Links internos: apontam para páginas relacionadas relevantes?
- [ ] Links externos: para fontes autoritativas quando cita dados?

### Imagens (P1)
- [ ] Alt text: descritivo, inclui variação da palavra-chave quando natural
- [ ] Tamanho: imagens comprimidas (WebP preferível)
- [ ] Nome do arquivo: descritivo (produto-azul.jpg > img001.jpg)

### Performance (P1)
- [ ] LCP < 2.5 segundos
- [ ] CLS < 0.1
- [ ] Mobile-friendly (teste no Search Console)

### Experiência (P2)
- [ ] Conteúdo responde a "People Also Ask" do SERP?
- [ ] Estrutura clara para featured snippet?
- [ ] Schema markup implementado quando aplicável?

## Formato de entrega

Para cada problema encontrado:
- **Problema**: descrição clara
- **Impacto**: Alto / Médio / Baixo
- **Correção**: ação específica a tomar
- **Prioridade**: P0 / P1 / P2
