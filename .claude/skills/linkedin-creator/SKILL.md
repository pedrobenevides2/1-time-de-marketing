# LinkedIn Creator

Crie conteúdo de alto engajamento para LinkedIn.

## Formatos e quando usar

| Formato | Melhor para | Alcance |
|---|---|---|
| Post de texto | Opinião, insight, história | Alto (algoritmo favorece) |
| Post com imagem | Dado visual, citação, bastidores | Médio-alto |
| Carrossel (PDF) | Passo a passo, lista, framework | Muito alto |
| Artigo | Conteúdo longo e técnico | Baixo (SEO de longo prazo) |
| Vídeo | Humanização, demonstração | Alto |

## Estrutura de post de texto

```
[HOOK — 1-2 linhas que param o scroll]

[ESPAÇO EM BRANCO — força o "ver mais"]

[CORPO — 3-7 parágrafos curtos, 1-3 linhas cada]
- Use listas quando possível
- Quebre linhas intencionalmente
- Dados e exemplos concretos

[CTA — pergunta ou chamada para ação]

[HASHTAGS — 3 a 5, relevantes, no final]
```

## Hooks que funcionam

- "X anos atrás eu errei feio."
- "Ninguém fala sobre isso, mas..."
- "O erro mais caro que vejo profissionais cometerem:"
- "Dado que me surpreendeu essa semana:"
- "Como [resultado concreto] em [tempo curto]:"

## Estrutura de carrossel

- Slide 1 (capa): título forte + promessa
- Slides 2-8: um ponto por slide, máximo 30 palavras
- Slide final: CTA + quem você é

## Regras

- Post deve funcionar sem imagem
- Primeiras 2 linhas = 80% do engajamento
- Evite link no post (coloque nos comentários)
- Responda todos os comentários nas primeiras 2h
- Publique entre 7-9h ou 17-19h dias úteis
