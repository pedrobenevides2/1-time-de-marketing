# Landing Page Copy

Gere o copy completo de uma landing page de alta conversão.

## Blocos obrigatórios

### 1. Hero (above the fold)
- **Headline**: promessa principal (o que o visitante ganha)
- **Subheadline**: como ou para quem
- **CTA primário**: botão com ação específica
- **Prova de credibilidade**: número, logo, selo

### 2. Problema / Agitação
- Nomeie a dor com precisão
- Mostre o custo de não resolver (financeiro, emocional, tempo)
- Crie identificação: "você já passou por isso?"

### 3. Solução / Produto
- O que é (em 1 frase simples)
- Como funciona (3 passos máximo)
- Para quem é (reforce o ICP)

### 4. Benefícios (não features)
- 3 a 6 benefícios principais
- Para cada: ícone + título + descrição curta
- Sempre do ponto de vista do cliente

### 5. Prova Social
- Depoimentos com nome, cargo e foto (se disponível)
- Logos de clientes conhecidos
- Números: usuários, resultados, avaliações

### 6. Objeções (FAQ ou seção dedicada)
- Liste as 4-5 principais objeções
- Responda de forma direta e honesta

### 7. CTA Final
- Repita a oferta principal
- Urgência ou garantia se aplicável
- Botão com microcopy que reduz fricção ("Comece grátis — sem cartão")

## Checklist de qualidade

- [ ] Headline foca em benefício, não em feature
- [ ] Subheadline qualifica o público
- [ ] CTA aparece pelo menos 3x na página
- [ ] Prova social próxima ao CTA principal
- [ ] Objeção de preço endereçada
- [ ] Mobile-first: parágrafos curtos, listas, espaçamento
