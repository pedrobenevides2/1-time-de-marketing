# Ebook Outline

## Posicionamento estratégico
- **Objetivo**: capturar leads qualificados (ofereça em troca de email)
- **Tamanho ideal**: 20-50 páginas (substancial o suficiente para ter valor)
- **Título**: promessa clara + resultado específico
  - Formato: "O Guia Completo de [TEMA] para [PÚBLICO]"
  - Formato: "Como [RESULTADO] em [PRAZO]: O Método [NOME]"

## Estrutura do ebook

```
CAPA
- Título impactante
- Subtítulo com promessa
- Imagem/ilustração profissional (Canva Free)
- Nome da empresa/autor

SOBRE ESTE EBOOK (0.5 página)
- Para quem é
- O que vai aprender
- Como usar o ebook

ÍNDICE

INTRODUÇÃO (1-2 páginas)
- Por que este tema importa agora
- Sua história/credibilidade no tema
- O que muda após ler

CAPÍTULO 1: FUNDAMENTOS / O PROBLEMA
CAPÍTULO 2: O FRAMEWORK / A METODOLOGIA
CAPÍTULO 3: PASSO A PASSO / IMPLEMENTAÇÃO
CAPÍTULO 4: EXEMPLOS / CASES
CAPÍTULO 5: ERROS COMUNS E COMO EVITAR

CONCLUSÃO
- Recapitulação dos aprendizados
- Próximos passos concretos
- CTA para serviço/produto

SOBRE A EMPRESA
REFERÊNCIAS (se aplicável)
```

## Design (sem custo)
- Canva Free: use templates "Ebook" prontos
- Paleta de cores da marca
- Ícones do Flaticon (plano grátis)
- Export como PDF

## Distribuição
- Landing page específica com formulário de captura
- Integrar com email marketing (Mailchimp free até 500 contatos)
