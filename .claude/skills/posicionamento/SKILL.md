# Posicionamento de Produto

## Colete as informações necessárias

1. Produto/serviço e o que faz
2. Para quem é (ICP — use `/icp-persona` antes se não tiver)
3. Principais concorrentes
4. Diferencial real (por que é melhor ou diferente)
5. Prova disso (dados, cases, depoimentos)

## Declaração de posicionamento

```
Para [ICP],
o [produto] é o [categoria]
que [benefício principal único]
diferente de [alternativas/concorrentes]
porque [prova / razão para acreditar].
```

## Proposta de valor (3 camadas)

**Funcional:** O que o produto faz objetivamente
**Emocional:** Como o cliente se sente ao usar
**Transformacional:** Em quem o cliente se torna

## Pilares de mensagem (3-4 temas centrais)

Para cada pilar:
- Nome do pilar
- Mensagem principal (1 frase)
- Prova / evidência
- Como usar em conteúdo
