# Produto GTM (Go-to-Market)

Crie um plano de lançamento completo em 4 fases.

## Informações necessárias

1. O que está sendo lançado?
2. Para quem (ICP — use `/icp-persona` se não tiver)?
3. Qual o diferencial principal?
4. Qual a data alvo de lançamento?
5. Qual o objetivo do lançamento? (usuários, receita, awareness)

## Plano GTM

### Fase 1 — Pré-lançamento (D-30 a D-7)
**Objetivo:** criar antecipação e base aquecida

- [ ] Definir posicionamento e mensagem principal (`/posicionamento`)
- [ ] Criar landing page de captura (`/landing-page`)
- [ ] Sequência de emails de pré-lançamento (3 emails)
- [ ] Conteúdo educativo sobre o problema que o produto resolve
- [ ] Recrutar beta testers / early adopters
- [ ] Preparar materiais de imprensa (`/press-release`)
- [ ] Briefing do time de suporte / vendas

### Fase 2 — Lançamento (D-7 a D0)
**Objetivo:** máxima visibilidade no dia do lançamento

- [ ] Email de anúncio para lista toda
- [ ] Posts coordenados em todos os canais sociais
- [ ] Release enviado para veículos relevantes
- [ ] Publicação no Product Hunt / comunidades (se aplicável)
- [ ] Ads ligados no dia D
- [ ] Live / evento de lançamento (se aplicável)

### Fase 3 — Pós-lançamento (D+1 a D+30)
**Objetivo:** converter interesse em uso ativo

- [ ] Sequência de onboarding por email
- [ ] Conteúdo de casos de uso e como usar
- [ ] Coleta de depoimentos dos primeiros usuários
- [ ] Análise de primeiros dados de uso
- [ ] Ajustes rápidos baseados em feedback

### Fase 4 — Avaliação (D+30)
**Objetivo:** medir resultado e definir próximos passos

- [ ] Revisão das métricas de sucesso definidas
- [ ] Relatório de aprendizados
- [ ] Decisão: continuar, pivotar ou ampliar

## Métricas de sucesso

Defina antes do lançamento:
- Métrica norte: ____
- Meta em 30 dias: ____
- Meta em 90 dias: ____
