# White Paper

## Tipos
- **Técnico**: para audiência técnica, detalha como funciona uma tecnologia ou processo
- **Executivo**: para tomadores de decisão, foca em ROI, riscos e oportunidades
- **Research**: baseado em dados/pesquisa original da empresa

## Estrutura completa

```
CAPA
- Título: problema + solução ou dado impactante
- Subtítulo: público e promessa
- Logo + data + autoria

SUMÁRIO EXECUTIVO (1 página)
- O problema central
- A solução proposta
- Principais conclusões (3-5 bullets)

1. INTRODUÇÃO / O PROBLEMA (1-2 páginas)
- Contexto de mercado com dados
- Dor específica do ICP
- Por que agora?

2. ANÁLISE DO PROBLEMA (2-4 páginas)
- Causas raízes
- Impactos quantificados
- Estado atual vs. estado desejado

3. ABORDAGENS EXISTENTES (1-2 páginas)
- O que o mercado faz hoje
- Limitações dessas abordagens
- Por que não são suficientes

4. A SOLUÇÃO / FRAMEWORK (3-5 páginas)
- Metodologia ou framework proprietário
- Passos de implementação
- Casos de uso com dados

5. RESULTADOS / EVIDÊNCIAS (1-2 páginas)
- Dados, métricas, cases
- Comparativo antes/depois

6. CONCLUSÃO + PRÓXIMOS PASSOS (0.5 página)
- Resumo de ações
- CTA para falar com a empresa

REFERÊNCIAS e SOBRE A EMPRESA
```

## Regras de qualidade
- Toda afirmação com fonte ou dado
- Tom consultivo, não comercial
- Gráficos e tabelas para dados complexos
- Lead magnet: ofereça em troca de email
