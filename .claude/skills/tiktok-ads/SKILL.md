# TikTok Ads

## Por que TikTok Ads vale

- CPM mais barato que Meta em nichos específicos (2024-2025)
- Spark Ads: impulsiona post orgânico existente — parece conteúdo natural
- Audiência jovem (18-34) com alto engajamento

## Tipos de anúncio

| Tipo | Descrição | Melhor para |
|------|-----------|------------|
| In-Feed Ads | Aparece no For You como post orgânico | Conversão, leads |
| Spark Ads | Impulsiona post orgânico ou de criador | Autenticidade, menor CPM |
| TopView | Primeiro vídeo ao abrir o app | Awareness (alto CPM) |
| Branded Hashtag | Desafio patrocinado | Viralizações de marca |

**Recomendado para começar sem gastar muito:** Spark Ads em posts que já performaram organicamente.

## Criativo para TikTok Ads (usando CapCut — grátis)

**Regra de ouro:** o anúncio deve parecer conteúdo orgânico, não anúncio.

```
[0-3s]  Hook visual + frase de abertura (para o scroll)
[3-10s] Contexto do problema
[10-25s] Solução / produto em uso real
[25-30s] CTA + oferta
```

**Elementos obrigatórios:**
- Formato vertical 9:16
- Legendas automáticas (80% assiste sem som)
- Música trending (TikTok Creative Center — grátis)
- UGC-style (câmera na mão, ambiente real) > produção polida

## Segmentação no TikTok Ads Manager

- **Interesse**: comportamento de consumo de conteúdo
- **Comportamento**: ações recentes (compras, vídeos assistidos)
- **Personalizado**: lista de clientes ou visitantes do site (Pixel)
- **Lookalike**: similar à sua lista de clientes

## Pixel TikTok

Instale o TikTok Pixel antes de qualquer campanha:
1. TikTok Ads Manager → Assets → Events → Web Events
2. Instale o Pixel no site via código ou integração
3. Configure eventos: ViewContent, AddToCart, Purchase

## Budget mínimo

- Conjunto de anúncios: mínimo $20/dia (TikTok exige em USD)
- Spark Ads: pode começar com $5/dia
- Fase de aprendizado: aguarde 3-5 dias antes de otimizar
