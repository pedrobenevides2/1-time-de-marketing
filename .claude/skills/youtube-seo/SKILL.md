# YouTube SEO

## Gere os metadados completos

### Título (50-60 caracteres)
- Palavra-chave principal no início
- Provoca curiosidade ou entrega clareza
- Formatos que funcionam:
  - "Como [resultado] em [tempo]"
  - "[Número] [coisas] que [audiência] precisa saber"
  - "Por que [afirmação surpreendente]"
  - "[Palavra-chave]: o guia completo"

### Descrição (5.000 chars disponíveis, use bem)
```
[Primeiras 2 linhas — aparecem sem clicar "ver mais"]
Resumo do vídeo + palavra-chave principal.
Link mais importante aqui: [URL]

⏱ CAPÍTULOS:
00:00 Introdução
00:XX [Tópico 1]
00:XX [Tópico 2]
...

📌 LINKS MENCIONADOS:
- [recurso 1]: [URL]

🔔 Se esse vídeo te ajudou, se inscreve e ativa o sino!

📲 Me segue nas redes:
Instagram: @
TikTok: @

#hashtag1 #hashtag2 #hashtag3
```

### Tags (10-15 tags)
```
[palavra-chave exata]
[variação 1]
[variação 2]
[termo mais amplo do nicho]
[nome do canal]
[termos relacionados]
```

### Hashtags (3-5, no final da descrição)
- 1 hashtag ampla do nicho
- 1-2 hashtags específicas do tópico
- 1 hashtag de marca (nome do canal)

### Briefing de thumbnail
```
Elementos obrigatórios:
- [ ] Rosto com expressão clara (se aparecer)
- [ ] Texto: máx 3 palavras, corpo 60pt+
- [ ] Contraste alto (teste em miniatura 120px)
- [ ] Cor diferente dos concorrentes no SERP
- [ ] Sem bordas brancas (some no fundo branco do YouTube)
```

## Ferramenta de pesquisa de palavras-chave (grátis)
- YouTube Search Autocomplete (digite e veja sugestões)
- Google Trends → YouTube Search
- TubeBuddy Free (extensão Chrome, básico gratuito)
