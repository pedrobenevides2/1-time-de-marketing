# Blog Post

## Coleta antes de escrever
1. Palavra-chave principal + intenção de busca (informacional/transacional)
2. Palavras-chave secundárias (3-5)
3. Público-alvo e nível de conhecimento
4. CTA final (o que o leitor deve fazer?)

## Estrutura

```
[TÍTULO SEO — 50-60 chars, palavra-chave no início]
[META DESCRIPTION — 150-160 chars, inclui CTA implícito]

INTRODUÇÃO (150-200 palavras):
- Hook: dado, pergunta ou situação que gera identificação
- Problema: o que o leitor quer resolver
- Promessa: o que vai aprender no artigo

H2: [Seção 1]
  H3: [Subseção se necessário]
  [Corpo: 250-400 palavras, dados, exemplos, listas]

H2: [Seção 2-5] — repita o padrão

CONCLUSÃO (100-150 palavras):
- Recapitule os pontos principais
- CTA claro e específico

[LINKS INTERNOS: 2-4 artigos relacionados]
[LINKS EXTERNOS: 1-2 fontes autoritativas]
```

## Regras SEO on-page
- Palavra-chave principal no H1, primeiro parágrafo e 1 H2
- Parágrafos máx. 3-4 linhas (leitura mobile)
- Imagem com alt text descritivo
- Tempo de leitura estimado no início
- FAQ no final se o tema tiver "People Also Ask"
