# Performance Marketing

Estruture ou audite campanhas de mídia paga com foco em ROI.

## Estrutura de campanha

```
Objetivo → Público → Criativo → Landing Page → Mensuração
```

### Por plataforma

**Meta Ads (Instagram/Facebook)**
- Campanha: objetivo (conversão, alcance, leads)
- Conjunto: público (interesse, lookalike, remarketing), orçamento, período
- Anúncio: formato (image, carrossel, vídeo), copy, CTA

**Google Ads**
- Rede de pesquisa: palavras-chave + match type + negative keywords
- Display/YouTube: público por intenção, tópico ou remarketing
- Performance Max: assets completos (textos, imagens, vídeos)

**LinkedIn Ads**
- Melhor para B2B (cargo, empresa, setor, sênioridade)
- Formatos: Sponsored Content, Message Ads, Lead Gen Forms

## Métricas essenciais por objetivo

| Objetivo | Métrica Principal | Secundária |
|---|---|---|
| Awareness | CPM, Alcance | Frequência |
| Consideração | CTR, CPC | Tempo na página |
| Conversão | CPA, ROAS | CVR |
| Retenção | CAC:LTV ratio | Churn |

## Otimização de criativos

- Teste 3-5 criativos por conjunto simultaneamente
- Hook nos primeiros 3 segundos (vídeo) ou primeira linha (texto)
- Criativo > segmentação na maioria dos casos
- Rotacione criativos a cada 2-3 semanas para evitar fadiga

## Checklist de lançamento

- [ ] Pixel/tag instalado e testado
- [ ] Eventos de conversão configurados
- [ ] UTMs em todos os links
- [ ] Exclusão de base de clientes existentes
- [ ] Público lookalike criado a partir de melhores clientes
- [ ] Landing page testada em mobile
- [ ] Orçamento diário definido com teto mensal
