# Infographic Brief

## Quando usar
- Dados com comparações ou rankings
- Processos passo a passo
- Estatísticas de mercado
- Timelines e históricos

## Tipos de infográfico

| Tipo | Quando usar |
|------|------------|
| Lista | Top X itens, dicas, erros |
| Processo | Passo a passo, fluxo |
| Comparação | A vs B, antes/depois |
| Dados/Estatísticas | Pesquisas, números de mercado |
| Timeline | História, evolução |
| Mapa | Dados geográficos |

## Estrutura do briefing

```
TÍTULO: [chamativo, max 8 palavras]
SUBTÍTULO: [contexto, max 12 palavras]
TIPO: [lista / processo / comparação / dados]

HIERARQUIA VISUAL:
1. Dado/informação principal (fonte maior)
2. Dados de suporte (fonte média)
3. Fontes e créditos (fonte pequena)

BLOCOS DE CONTEÚDO:
Bloco 1: [título] + [texto/dado] + [ícone sugerido]
Bloco 2: ...

CORES: [paleta da marca ou sugestão]
ESTILO: [clean / colorido / dark / minimalista]

FONTE DOS DADOS: [cite todas as fontes]
LOGO E URL: [incluir no rodapé]
```

## Ferramentas gratuitas para criar
- **Canva Free**: templates "Infographic" prontos
- **Piktochart Free**: até 5 infográficos gratuitos
- **Visme Free**: plano limitado mas funcional
- **Ícones**: Flaticon.com (plano grátis com atribuição)

## Distribuição
- PNG/JPG para redes sociais
- PDF para blog e email
- Pinterest tem alto tráfego orgânico para infográficos
